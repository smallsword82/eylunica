# Varlıklar

Karakter SVG çizimleri (`src/ui/Avatar.tsx`), sahne/dünya CSS çizimleri, uygulama SVG/PNG ikonları bu proje için sıfırdan oluşturuldu. Harici görsel, fotoğraf, şarkı veya font kullanılmadı. Sistem fontları kullanılır. Bağımlılık lisansları kendi npm paketlerinde bulunur; dağıtım öncesi üçüncü taraf lisans bildirimi hazırlanmalıdır. Depo için genel bir açık kaynak lisansı seçilmedi; depo özel tutulur.
